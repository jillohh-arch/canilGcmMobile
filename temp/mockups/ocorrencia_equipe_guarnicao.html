      { handler_id, name, ra, role: "relator" },
      { handler_id, name, ra, role: "integrante" }
    ],

  }

  { handler_id, signed_at, method: "biometria" }

  { ..., dog_handler_id }   // quem conduziu o cao NAQUELA acao

Fluxo

1
Guarnição ativa — condutores na viatura + cão de serviço do turno
2
Cria ocorrência — captura a guarnição inteira (snapshot)
3
Fecha p/ assinaturas — trava edição; condutores notificados
4
Todos assinam — vira resultado final + selo (hash v3)

Comportamento & regras

  • Um único cão por viatura/turno. App só registra qual cão saiu — sem burocratizar a escolha (que é informal).
  • Condutores são iguais. Qualquer um pode conduzir o cão; não há "dono" fixo na viatura.
  • Emprego do cão por ação. Quando o cão trabalha (faro/captura), registra-se o condutor daquele momento — e o crédito vai ao K9 ("K9 Bono localizou o entorpecente").
  • Guarnição indivisível. Equipe = guarnição inteira, sem ajuste/remoção.
  • Assinatura: todos os condutores assinam (biometria). O cão é membro com presença atestada pela guarnição — não assina.
  • Hash v3 inclui conductors, service_dog e signatures no payload (mantido da Parte 10).
